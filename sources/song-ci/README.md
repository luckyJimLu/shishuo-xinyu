# 宋词选集底本

`provenance.json` 记录固定提交、原始地址、MIT许可及SHA-256。`song300.original.json` 保留下载字节，实际280首、83位作者。`LICENSE` 来自同一提交的仓库根目录。

`npm run import:song-ci` 使用OpenCC转换简体并确定性生成正文及许可证。底本只提供作者、词牌和分句，不提供上下阕界线、逐首题名、注译或编年；不根据句数补造分阕。阅读题名附首句帮助区分同调作品，不改写正文。稳定ID取自原始作者、词牌和全文SHA-256的前24位；重新排序不改变ID，原文变更需审查路由迁移。底本中的异文及作者题署仍需后续文献校勘，本次不宣称专家审定。
